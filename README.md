# C++ 起步实验室

这是一个面向零基础学习者的 C++ 交互学习网页：先预测结果，再逐步观察程序状态，最后独立练习。

[打开学习网页](https://delta-song.github.io/cpp-learning-site/)

## 课程

目前开放第 1 至第 11 周，共 77 课。内容从基础语法、循环、数组与字符串，逐步进入函数、排序、前缀和、差分及二分查找。第十一周包含有序查找、上下界、单调可行性和连续分段的答案二分。

## 怎么学

1. 选择周次与课程，阅读讲解并先写下预测。
2. 修改示例输入，逐步观察固定教学演示中的变量、代码行和输出。
3. 使用分层提示后，关闭答案并独立重写；在本地 C++ 环境编译练习题。

网页只展示预设 C++ 示例的教学轨迹，不会编译或运行任意代码，也不提供在线判题。

## 学习记录与本地使用

网页无需登录。作答、提示、完成方式和笔记保存在当前浏览器的 localStorage 中，不会自动跨设备同步；清除浏览器数据可能删除记录。

下载仓库后打开 `index.html` 即可本地学习，无需安装依赖。部分外部练习链接需要联网。
