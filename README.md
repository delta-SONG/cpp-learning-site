# C++ 起步实验室

面向零基础学习者的 C++ 交互式学习网页，通过预测结果、单步观察和动手练习，逐步理解程序的运行过程。

**[打开学习网页](https://delta-song.github.io/cpp-learning-site/)**

## 如何使用

1. 打开网页，选择学习周次和课程。
2. 阅读概念并预测结果，再单步观察代码、变量和输出的变化。
3. 根据课程提示，在自己的编程环境中编写和运行 C++ 程序，并记录练习情况。

当前开放第 1 至第 10 周，共 70 课，涵盖基础语法、循环、数组、字符串、函数、排序和差分等内容。网页适配电脑、平板和手机。

## 使用须知

- 网页无需登录；学习记录保存在当前设备的浏览器中，不会自动跨设备同步。清除浏览器数据可能删除记录。
- 网页中的互动实验展示预设示例的教学过程，不是 C++ 编译器，也不支持运行任意代码或在线判题。
- 课程中部分练习链接指向洛谷，需要联网；是否登录洛谷由你自行决定。

## 本地使用

下载仓库文件后，用浏览器打开 `index.html` 即可。网页本身无需安装依赖。
