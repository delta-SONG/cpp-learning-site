# C++ 起步实验室

这是一个给零基础学习者使用的 C++ 学习网页。你可以先猜一猜代码会输出什么，再一步步观察变量和输出的变化，最后动手练习。

[打开学习网页](https://delta-song.github.io/cpp-learning-site/)

## 怎么学

1. 打开网页，选择学习周次和课程。
2. 阅读讲解，预测结果，再单步观察代码的运行过程。
3. 按课程提示，在自己的编程环境中编写、运行 C++ 程序，记录练习情况。

目前开放第 1 至第 10 周，共 70 课，内容包括基础语法、循环、数组、字符串、函数、排序和差分等。电脑、平板和手机都可以访问。

## 使用时要知道

- 网页无需登录。学习记录保存在当前设备的浏览器里，不会自动同步到其他设备；清除浏览器数据可能会删除记录。
- 互动实验展示的是预设示例的教学过程。网页不能编译或运行任意 C++ 代码，也不能在线判题。
- 部分练习链接指向洛谷，打开这些链接需要联网；是否登录洛谷由你自行决定。

## 在本地打开

下载仓库文件后，用浏览器打开 `index.html` 即可，无需安装依赖。
